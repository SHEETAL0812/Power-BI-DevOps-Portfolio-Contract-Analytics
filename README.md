# Power BI DevOps Portfolio: Contract Analytics

A Power BI project built as a developer-style repo: `.pbip` + TMDL, version-controlled with Git, with CI checks on GitHub Actions planned.

> Data is **synthetic** (generated by a script), so the repo is safe to make public.

## Data model
- `Contracts` (fact): 700 contracts with type, status, dates, value (EUR), review cycle days
- `Counterparties` (dim): 60 companies with country
- `Departments` (dim): 8 departments
- `Date` (dim): calculated date table (2023-2030)

## Measures (written in TMDL)
| Measure | Folder | Purpose |
|---|---|---|
| Total Contracts | Volume | Count of all contracts |
| Active Contracts | Volume | Contracts with status Active |
| Expired Contracts | Volume | Contracts with status Expired |
| Active Share % | Volume | Active contracts as a share of all contracts |
| Total Value (EUR) | Value | Sum of contract value |
| Avg Contract Value (EUR) | Value | Average contract value |
| Avg Review Cycle (Days) | Process | Average days spent in review |
| Expiring Next 90 Days | Risk | Active contracts ending within 90 days |

## Week 1: .pbip and TMDL

### Using GitHub Copilot to write TMDL
I described three measures in plain English in Copilot Chat (Edit mode, with `Contracts.tmdl` as context), accepted the change in VS Code, and then checked it two ways:
1. Opened the project in Power BI Desktop to confirm the TMDL was valid.
2. Checked the values by hand (for example, Active Share % against Active Contracts divided by Total Contracts).

I reviewed the exact lines changed in the Git diff before committing.

### What I learned
- Saving as `.pbip` splits the report into plain text files: the report pages and visuals are JSON, and the data model (tables, measures, relationships) is TMDL.
- TMDL is strict about structure. An object's own properties (like `lineageTag`) must come before its child objects (measures, columns), and indentation must use tabs consistently. I hit this error when opening the project and fixed it by moving the property line.
- AI can write TMDL from plain English, but I verify it every time: the project must open without errors, the numbers must be checked by hand, and the Git diff shows exactly what changed.
